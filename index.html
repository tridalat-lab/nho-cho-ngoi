📋 Hướng Dẫn

  1. Tạo Google Sheet mới (trống)
  2. Mở Extensions → Apps Script
  3. Paste code từ file Code.gs vào
  4. Bấm Deploy → New deployment
  5. Chọn Type: Web app, Execute as: Me, Access: Anyone
  6. Copy URL và paste vào ô bên dưới
